# Python Tutorials

This repository contains simple Python tutorials for beginners.  
It covers basic concepts of Python with examples and practice programs.

## Topics Covered

1. Introduction to Python
2. Variables and Data Types
3. Operators
4. Conditional Statements (if, else, elif)
5. Loops (for, while)
6. Functions
7. Lists, Tuples, Sets, Dictionaries
8. File Handling
9. Exception Handling
10. Object-Oriented Programming (OOP)

## Requirements

- Python 3.x installed on your system
- Any code editor (VS Code, PyCharm, Notepad++, etc.)

Check Python version:

python --version

## How to Run the Programs

1. Download or clone the repository

git clone https://github.com/your-username/python-tutorials.git

2. Go to the project folder

cd python-tutorials

3. Run any Python file

python filename.py

Example:

python variables.py

## Who Can Use This

- Beginners learning Python
- Students practicing programming
- Anyone who wants to understand Python basics
